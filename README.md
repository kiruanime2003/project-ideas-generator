# Project Ideas Generator

Generates project ideas from live news. The website gets refreshed every 12 hours at 6am and 6pm.

## Tech Stack
- Frontend - ReactJS
- Backend - ExpressJS, NodeJS
- Database - MongoDB
- API - Google gemini and grok
